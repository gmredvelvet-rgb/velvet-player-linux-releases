# Velvet Player Linux downloads

Download the newest versioned preview release from this repository. It contains only release packages and public update metadata; source is maintained separately.

For Linux x86_64 PCs using an X11 desktop and Steam Deck Desktop Mode. Native Steam and Proton are required for TaleSpire Full or Guest Edition. Wayland, Gaming Mode and Flatpak Steam are outside the preview. Real game/hardware validation is ongoing.

Install 0.1.1 or later once: download the .tar.gz and its matching .sha256, verify and extract them on Linux, then run ./install.sh without sudo. Open Velvet Player Linux from the applications menu. Use the included README for the Proton launch option and Symbiote setup.

Future releases are offered inside the launcher through Check for updates and Update & restart. The client verifies signed metadata, file size and SHA256 before installation. No GitHub account or token is needed. The linux-preview release stores the signed channel metadata; use the versioned release to download the installer archive.

Your Foundry login, player invitation and local bridge token are separate from downloads. Never share credentials or bridge tokens when reporting a problem.
